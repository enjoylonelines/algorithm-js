# [level 2] 땅따먹기 - 12913

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12913)

### 문제 설명

N행 4열로 이루어진 땅이 있습니다. 각 칸에는 점수가 적혀 있으며, 1행부터 N행까지 아래로 내려가면서 칸을 하나씩 선택합니다.

단, 같은 열을 연속으로 선택할 수 없습니다. 즉, 어떤 행에서 선택한 열 번호와 바로 다음 행에서 선택한 열 번호가 달라야 합니다.

이 규칙에 따라 이동했을 때 얻을 수 있는 점수의 최댓값을 구하세요.

### 입출력 형식

- 입력
  - `land`: 각 행의 점수를 담은 N×4 크기의 2차원 정수 배열
  - `n`: 행의 수 (정수)
- 출력: 얻을 수 있는 점수의 최댓값 (정수)

### 제한사항

- 행의 수 N은 100 이상 100,000 이하입니다.
- 각 칸의 점수는 0 이상 100 이하인 정수입니다.

### 입출력 예

| land | n | result |
|---|---:|---:|
| [[1,2,3,5],[5,6,7,8],[4,3,2,1]] | 3 | 16 |
| [[4,3,2,1],[2,2,2,2],[1,1,3,1]] | 3 | 9 |
| [[1,1,1,1]] | 1 | 1 |
