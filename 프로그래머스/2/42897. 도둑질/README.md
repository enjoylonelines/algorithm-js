# [level 2] 도둑질 - 42897

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42897)

### 문제 설명

일직선으로 이어진 집들을 순서대로 방문하며 도둑질을 하려고 합니다. 각 집에는 훔칠 수 있는 돈이 담겨 있습니다. 단, 인접한 두 집을 털게 되면 경보가 울리므로 서로 이웃한 집을 털 수 없습니다.

집들이 원형으로 배치되어 있어 첫 번째 집과 마지막 집도 서로 이웃합니다. 각 집에 담긴 돈이 주어질 때, 경보를 울리지 않고 훔칠 수 있는 돈의 최댓값을 구하세요.

### 입출력 형식

- 입력: 집에 있는 돈을 순서대로 담은 정수 배열 `money`
- 출력: 경보를 울리지 않고 훔칠 수 있는 돈의 최댓값 (정수)

### 제한사항

- `money`의 길이는 3 이상 1,000,000 이하입니다.
- `money`의 각 원소는 0 이상 100 이하인 정수입니다.
- 모든 집을 털 수 있는 경우는 주어지지 않습니다.

### 입출력 예

| money | result |
|---|---:|
| [1, 2, 3, 1] | 4 |
| [1, 2, 3, 1, 2] | 5 |
| [90, 0, 0, 95, 1, 2] | 185 |
