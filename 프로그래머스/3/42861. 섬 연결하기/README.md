# [level 3] 섬 연결하기 - 42861

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42861)

### 문제 설명

n개의 섬 사이에 다리를 놓아 모든 섬을 서로 통행할 수 있도록 만들려고 합니다. 섬의 개수 n, 다리를 놓는 데 드는 비용(costs)가 주어질 때, 모든 섬을 연결하는 최소 비용을 구하세요.

costs에는 다리를 둘 수 있는 섬의 쌍과 그 비용이 주어집니다. costs[i][0]과 costs[i][1]은 다리로 연결할 수 있는 섬의 번호이고, costs[i][2]는 비용입니다. 같은 섬 쌍에 대한 비용은 항상 하나만 주어지며, 모든 섬 사이에 다리를 둘 필요는 없습니다. 하지만 모든 섬은 직접 또는 다른 섬을 통해 연결되어야 합니다.

### 입출력 형식

- 입력
  - `n`: 섬의 개수 (정수)
  - `costs`: 각 다리의 정보 `[from, to, cost]`를 담은 2차원 배열
- 출력: 모든 섬을 연결하는 데 필요한 최소 비용 (정수)

### 제한사항

- 섬의 개수 n은 1 이상 100 이하입니다.
- costs의 길이는 `((n-1) * n) / 2` 이하입니다.
- 임의의 i에 대해, costs[i][0] 과 costs[i][1]은 다르며, 0-indexed입니다.
- 어떤 이유로 두 섬 사이에 다리를 놓지 못하는 경우는 주어지지 않습니다.
- 모든 섬을 연결하는 경우는 항상 존재합니다.

### 입출력 예

| n | costs | result |
|---|---|---|
| 4 | [[0,1,1],[0,2,2],[1,2,5],[1,3,1],[2,3,8]] | 4 |
| 2 | [[0,1,5]] | 5 |
| 3 | [[0,1,3],[1,2,2],[0,2,6]] | 5 |

### 입출력 예 설명

**예 1**: 4개의 섬이 있고 다리 비용은 위와 같습니다. 0-1(비용 1), 0-2(비용 2), 1-3(비용 1)을 이으면 모든 섬이 연결되며 총 비용은 1+2+1 = 4입니다. 이보다 적은 비용으로는 모든 섬을 연결할 수 없습니다.

**예 2**: 섬이 2개이므로 유일한 다리를 놓으면 되며 비용은 5입니다.

**예 3**: 3개의 섬을 연결하려면 최소 2개의 다리가 필요합니다. 1-2(비용 2), 0-1(비용 3)을 이으면 총 비용 5로 모든 섬을 연결할 수 있습니다.
