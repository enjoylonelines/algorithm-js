# [level 3] 등굣길 - 42898

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/42898)

### 문제 설명

집에서 학교까지 가는 길은 m×n 크기의 격자로 이루어져 있습니다. 집은 가장 왼쪽 위 칸(1, 1)에, 학교는 가장 오른쪽 아래 칸(m, n)에 위치합니다.

이동은 오른쪽 또는 아래 방향으로만 가능하며, 물에 잠긴 칸(puddles)은 지나갈 수 없습니다.

집에서 학교까지 도달할 수 있는 경로의 수를 1,000,000,007로 나눈 나머지를 구하세요.

### 입출력 형식

- 입력
  - `m`: 격자의 가로 크기 (열 수, 정수)
  - `n`: 격자의 세로 크기 (행 수, 정수)
  - `puddles`: 물에 잠긴 칸의 좌표 목록 (각 원소는 [열, 행])
- 출력: 경로의 수를 1,000,000,007로 나눈 나머지 (정수)

### 제한사항

- 격자의 크기 m, n은 1 이상 100 이하입니다.
- 물에 잠긴 칸의 수는 10 이하입니다.
- 집과 학교가 있는 칸은 물에 잠기지 않습니다.
- 시작점에서 도착점까지 항상 도달 가능한 경우만 입력으로 주어집니다.

### 입출력 예

| m | n | puddles | result |
|---:|---:|---|---:|
| 4 | 3 | [[2,2]] | 4 |
| 3 | 3 | [] | 6 |
| 4 | 3 | [] | 10 |
